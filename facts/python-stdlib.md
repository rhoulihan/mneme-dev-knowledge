- [gotcha] argparse's action=version raises SystemExit, which escapes an in-process main() under test — implement version flags as store_true when you test CLIs in-process #python #argparse #testing (verified: 2026-08-12)
- [gotcha] SQLite URI filenames treat hash, question mark, and percent specially — percent-encode paths before building file: URIs or mode=ro silently drops and the wrong file opens #sqlite #security (verified: 2026-08-12)
- [constraint] CPython's bundled SQLite ships with FTS5 enabled on mainstream Linux, macOS, and Windows builds, so full-text search needs no third-party dependency #sqlite #python (verified: 2026-08-12)
